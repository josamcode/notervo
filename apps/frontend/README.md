# Notervo storefront

Customer-facing React application, built with Vite and Tailwind CSS.

Run `npm run dev:store` from the repository root. The development server uses http://localhost:3000. Set `VITE_API_URL` in `.env.local`; see `.env.example`.

Run `npm run build --workspace=@notervo/storefront` to generate `dist/`, and `npm test --workspace=@notervo/storefront` for utility tests.

See the [root README](../../README.md) and [development guide](../../docs/development.md) for complete setup.
